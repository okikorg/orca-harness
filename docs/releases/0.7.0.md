Orcacode's first public release: the source is now open under the Apache License 2.0. It also adds orchestrate mode, persistent sidekick agents, and a much larger Rust SDK.

## Open source

- Orcacode and Orca Harness are now licensed under the Apache License 2.0 (`LICENSE`, `NOTICE`). Earlier releases were proprietary.
- New README, screenshots, and a refreshed field manual at https://orcapods.ai/orcacode/docs/.

## Highlights

- Orchestrate mode (`/mode orchestrate`, `--orchestrate`): the parent investigates, makes basic edits, and delegates substantial work to subagents and workflows.
- Sidekicks: session-long workers that keep their context between follow-up tasks (`/sidekick <task>`, `/sidekick stop`, or `persistent: true` on the `subagent` tool). They survive model and provider switches and stop on `/clear`, session load and exit.
- After plan mode writes a plan, Orcacode asks whether to approve it and start implementing.
- MCP servers connect in the background, so startup no longer waits on them.
- Resume a session by ID from any workspace (`orcacode resume ID`).
- Provider failures are shown as readable text instead of raw JSON.
- The Codex provider requests catalog client version 0.155.1, which lists gpt-6-sol and gpt-6-luna.

## Rust SDK

- `Agent::run` one-shot convenience, and grouped `contracts`, `providers`, `orchestration` and `integrations` namespaces.
- Session-owned tool state, context import, run continuation, caller cancellation, and partial run outcomes.
- Typed subagent, background process and workflow operations, shared with the model-facing tools, with session-owned delivery and shutdown.
- Per-run MCP tool capture and skill refresh, owned skill previews, and classified tool and model retries.

## Fixes

- Stream chunks that send `null` for a list (seen from CheaperInference) no longer fail the run with a "bad stream chunk" error.
- Headless text output no longer runs answer text, reasoning and tool rows together on one line.
- Worker budgets are preserved and orchestration telemetry is exposed.
- Only live processes count against the process spawn cap.
- Background completions are announced reliably at run end and after an inbox reset.

## Install

macOS / Linux:

```sh
curl -fsSL https://orcapods.ai/orcacode.sh | sh
```

Windows (PowerShell):

```powershell
irm https://orcapods.ai/orcacode.ps1 | iex
```
