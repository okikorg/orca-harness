A terminal-UI pass for the orcacode CLI: inline `!cmd` shell output, a compact agent view with per-subagent model selection, refined provider model selection, and skills that load once per conversation.

## Highlights

- show !cmd shell output inline after it finishes
- configure subagent models and compact agent UI
- refine terminal UI and provider model selection
- load a skill once per conversation

## Other changes

- centralize tool activity labels

## Install

macOS / Linux:

```sh
curl -fsSL https://orcapods.ai/orcacode.sh | sh
```

Windows (PowerShell):

```powershell
irm https://orcapods.ai/orcacode.ps1 | iex
```
