This release lets subagents run in the background and gives you control over which models they use.

## Highlights

- Subagents can run detached in the background. A completion inbox wakes the parent when one finishes, and the TUI gains an agent browser with tabs for switching between them.
- `/subagents` is now a live settings panel shared across the parent and workers and persisted to config. It includes a background concurrency limit and model routing per subagent: inherit, auto, a preferred model, or a tier.
- Model gates admit or hold requests per model, and the OpenAI and Codex providers honour `Retry-After` and classify HTTP errors so retries are driven by the server's guidance rather than a fixed backoff.

## Fixes

- The `/subagents` route and preferred models survive agent rebuilds (`/clear`, `/model`, `/provider`, config reloads) instead of resetting to defaults.

## Install

macOS / Linux:

```sh
curl -fsSL https://orcapods.ai/orcacode.sh | sh
```

Windows (PowerShell):

```powershell
irm https://orcapods.ai/orcacode.ps1 | iex
```
