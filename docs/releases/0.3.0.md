This release makes long-running process work more efficient and keeps release changes easy to inspect inside Orcacode.

## Highlights

- Detached processes can wake the interactive agent when they exit or when a one-shot literal output match appears.
- Finite long-running commands can use `waitForExit` to return once at completion instead of requiring repeated polling.
- `/changelog` shows the latest release changes, while `/changelog full` shows the full bundled history.
- Orcacode reports when an update is available at startup.

## Fixes

- Background-process notifications are generation-scoped so stale processes cannot resume a replaced or cleared conversation.
- Process output already returned by a tool call is not repeated in later notifications.
- Explicit process termination does not generate a duplicate exit notification.

## Install

macOS / Linux:

```sh
curl -fsSL https://orcapods.ai/orcacode.sh | sh
```

Windows (PowerShell):

```powershell
irm https://orcapods.ai/orcacode.ps1 | iex
```
