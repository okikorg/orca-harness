The second binary release of `orcacode`, the terminal host for Orca Harness. Built from this tag with the release profile (fat LTO, stripped); single static executables.

## Highlights

- **Vercel AI Gateway** as a first-class provider. Point orcacode at `ai-gateway.vercel.sh` with `AI_GATEWAY_API_KEY`; `--provider vercel` or `/provider` in the TUI.
- **File mutation tooling.** Core write, edit, and patch tools with a unified patch format and an approval workflow, including a default auto-approval mode.
- **Subagents.** Routing preferences are enforced when a task fans out to a subagent.
- **TUI.** Clipboard image paste, a wrapping composer with a stacked split and anchored live region, a priority-dropping status bar, an approval prompt, glyph styles, and inline mermaid rendering.
- **Robustness.** Truncated OpenAI tool calls are handled, and routine auto shell checks are faster.

## Install

macOS / Linux:

```sh
curl -fsSL https://orcapods.ai/orcacode.sh | sh
```

Windows (PowerShell):

```powershell
irm https://orcapods.ai/orcacode.ps1 | iex
```
