Streaming responses reuse rendered Markdown and batch incoming updates, keeping the TUI responsive to typing, cancellation, and approvals. This release also includes the provider and status improvements prepared for 0.6.0.

## Performance

- Cache unchanged streaming Markdown across keyboard, scrolling, and animation frames. Text, terminal width, theme, and glyph changes invalidate the cache.
- Coalesce worker updates into scheduled redraws, with bounded batches and priority for keyboard input and approval prompts.
- Reduce repeated work in workflow scheduling and provider request construction.
- Tighten startup and add benchmark coverage.

## Highlights

- Add CheaperInference as a configurable provider.
- Give the glyph status bar dedicated marks and show streamed token estimates alongside run progress.

## Fixes

- Preserve the underlying cause of provider transport failures.
- Trust the system certificate store alongside bundled certificate roots.
- Expand coverage for provider streaming, workflow contracts, and TUI event ordering.
