A native Anthropic Messages API provider, plus token-accounting fixes for OpenRouter cache writes and the TUI.

## Highlights

- native Anthropic Messages API provider (#22)

## Fixes

- stop double-counting OpenRouter cache writes into input_tokens (#20)
- remove separate thinking token count

## Other changes

- pin the Rust toolchain to 1.98.1 (#21)
- correct the license metadata: the project is proprietary, not MIT (LICENSE added)

## Install

macOS / Linux:

```sh
curl -fsSL https://orcapods.ai/orcacode.sh | sh
```

Windows (PowerShell):

```powershell
irm https://orcapods.ai/orcacode.ps1 | iex
```
