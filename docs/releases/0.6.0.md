CheaperInference joins the provider lineup, the glyph status bar gets its own marks, and network failures now carry their underlying cause instead of a bare transport error.

## Highlights

- give the glyph status bar its own marks (#17)
- add CheaperInference as a provider

## Fixes

- report transport failures with their cause
- keep the cause when a transport error becomes a ModelError (#16)
- trust the system certificate store, not only webpki roots (#15)

## Other changes

- tighten the startup path and add benchmark gates (#18)
- give every provider its own module directory

## Install

macOS / Linux:

```sh
curl -fsSL https://orcapods.ai/orcacode.sh | sh
```

Windows (PowerShell):

```powershell
irm https://orcapods.ai/orcacode.ps1 | iex
```
