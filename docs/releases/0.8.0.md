Orcacode 0.8.0 refreshes the terminal interface, simplifies the default tools, preserves images returned by tools, and discovers the latest Codex models.

## Highlights

- Refreshed terminal components, split pane tabs, and mark and branch settings.
- Codex catalog compatibility updated to 0.159.2, making `gpt-6.1-sol` available when enabled for your account.
- Images returned by tools reach the model as images, with their order and labels preserved per call.

## Tool changes

- `edit_file` handles either one `{path, old, new}` edit or an ordered, transactional `edits` batch across files. It replaces `multi_edit` and `apply_patch`.
- `glob` and `shell` cover directory listing; `list_dir` is removed.
- `web_search` and `web_fetch` remain; `web_crawl` is removed.
- Interactive plan mode allows shell commands with a yes/no approval for every command. Headless plan mode and workers continue to deny shell access.
- Update custom tool allowlists that reference the removed tools.

## Documentation

- Updated external manual, measured startup latency, and five-harness comparisons.
- Added contribution guidelines and a harness-core patch folder.

## Install

macOS / Linux:

```sh
curl -fsSL https://orcapods.ai/orcacode.sh | sh
```

Windows (PowerShell):

```powershell
irm https://orcapods.ai/orcacode.ps1 | iex
```
