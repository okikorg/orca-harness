Orcacode 0.10.0 makes headless mode a usable engine for other hosts: session ids in the JSON stream, per-run MCP servers, prompts from stdin, approvals over stdio, a read-only mode, and image attachments.

## Highlights

- `--json` `metadata` and `summary` events carry `sessionId` (the full id, for new and resumed sessions; `null` only with `--no-session`), so a host can `--resume` exactly the session it started. `metadata` also reports `resumed`, `readOnly`, `approvals` and `mcpServers`.
- `--mcp-config <json|file>` adds MCP servers for one run: `{"name":{"command":"...","args":[...],"env":{...},"cwd":"..."}}`, or the same map under `mcpServers`. The command runs without a shell, so paths and arguments may contain spaces; `env` is merged over the inherited environment. Run servers are never saved to `config.json`, and one with a saved server's name replaces it for that run.
- `-p -` reads the prompt from stdin and `--prompt-file PATH` reads it from a file, so long prompts and prompts that start with `-` are safe.
- `--approvals stdio` (with `--json`): gated tool calls emit an `approval_request` event (`id`, `tool_call_id`, `tool_name`, `input`) and wait for `{"type":"approval","id":"...","decision":"allow"|"deny"|"always"}` on stdin. Concurrent requests are matched by id, subagent children ask the same way, and EOF denies. The default stays `deny`.
- `--read-only`: no file writes anywhere (stricter than `--plan`), no compute, delegation or memory writes; MCP tools stay usable, and `shell` runs only when the caller approves each command over `--approvals stdio`. `--auto-approve` and `--yolo` do not widen it.
- `--image PATH` (repeatable) attaches png, jpg, gif or webp files to the headless prompt.
- `summary.status` distinguishes `max_steps` and `cancelled` from `error`.
- The headless NDJSON event union is documented in `crates/cli/README.md`.

## Install

macOS / Linux:

```sh
curl -fsSL https://orcapods.ai/orcacode.sh | sh
```

Windows (PowerShell):

```powershell
irm https://orcapods.ai/orcacode.ps1 | iex
```
