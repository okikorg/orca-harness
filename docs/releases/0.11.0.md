Orcacode 0.11.0 lets a host pick any provider and model per run, and list providers and models as JSON.

## Highlights

- `--provider LABEL` (openrouter, vercel, cheaperinference, openai, openai-codex, anthropic, local) selects the provider for one run, `--list-models` or `--list-providers`, overriding the saved provider without writing to `config.json`. Without `--model` it uses that provider's saved model or its default.
- `--list-providers --json` prints every provider with its auth kind (`api_key`, `oauth`, `none`), whether it is configured, and its saved or default model, plus the active provider. No network calls, and no key values.
- `--list-models --json` prints `{"provider", "models": [{"id", "name", "contextWindow", "efforts"}]}`; the plain-text listing is unchanged.

## Install

macOS / Linux:

```sh
curl -fsSL https://orcapods.ai/orcacode.sh | sh
```

Windows (PowerShell):

```powershell
irm https://orcapods.ai/orcacode.ps1 | iex
```
