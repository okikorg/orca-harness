01 · STAKES

Why microseconds matter

Model steps cost seconds, tools cost milliseconds. If dispatch cost 1 ms per call, a 100-file read batch pays 100 ms of pure overhead — 70× the real 1.4 ms of work. At ~0.4 µs/call it pays ~40 µs: nothing. The kernel disappears and you only pay for model + tools.

Noise floorCriterion's default 1% threshold sits below this machine's ~1.5% run-to-run drift — the workspace uses noise_threshold(0.03). Real dispatcher changes measure 5–20%; don't chase phantoms under 3%.
