# Startup benchmarks

Measures fixed `orcacode` host startup costs with isolated HOME, config,
session, workspace, and skill fixtures generated by `../shared/fixtures.py`.
Requires `hyperfine` and Python 3.

```bash
./benchmarks/startup/run.sh
./benchmarks/startup/run.sh --quick
./benchmarks/startup/run.sh --ci
```

Generated Hyperfine JSON and `summary.json` are written to
`benchmarks/results/startup/`. The runner applies Linux-only shared budgets
through `../shared/check_budgets.py`. See the root
[`benchmarks/README.md`](../README.md) for workload definitions and fixture
isolation rules.
