Cache threshold

Prompt caching was enabled for Orcacode and confirmed by raw request metadata, but neither harness reported cache usage. The largest model steps were 3,326 input tokens for Orcacode and 3,752 for Pi, below Haiku 4.5’s 4,096-token minimum cacheable prefix. This validates enablement, not cache economics.

Reproduction method

How the benchmark was run

The runner was written before execution so scheduling, isolation, capture, and scoring remained identical across both harnesses.

1 · Schedule

Sixteen task fixtures, two harnesses, one repetition: 32 total attempts. The schedule alternated harness order by task to reduce warm-up and time-of-run bias.

2 · Isolation

Each attempt received a fresh temporary workspace copied from its fixture. Harnesses ran headlessly and could modify only that disposable copy.

3 · Capture

Raw JSONL events preserved wall time, startup, end-to-end and model TTFT, first-answer and first-tool timings, token classes, tool calls, turns, exit status, and timeout state.

4 · Validation

Deterministic validators checked requested answers and workspace state. Edit tasks used exact fixture validation; answer and workspace correctness remained separate.

5 · Aggregation

Per-task values are the single measured attempts in this rerun. Aggregate totals sum all attempts; aggregate medians span the 16 attempts. Cost applies one normalized price schedule to reported usage.

6 · Audit trail

The run directory retains the manifest, summary JSON and Markdown, normalized CSV/JSON rows, and all 32 raw event streams for independent inspection.

Interpretation boundary

What this result does and does not show

Comparative evidence

This single-repetition rerun provides directional evidence that the captured Orcacode build outperformed Pi 0.84.2 on this 16-task fixture suite, using Claude Haiku 4.5 at low effort in the recorded environment. It does not establish universal harness superiority, production billing, or performance on other models, repositories, prompts, machines, concurrency levels, or interactive workflows. Prompt caching was enabled for Orcacode, but neither harness crossed the 4,096-token cacheable-prefix threshold. A matched cache-economics test needs a controlled repeated prefix above that minimum.
